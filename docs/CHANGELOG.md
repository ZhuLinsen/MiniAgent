# Changelog

## [Unreleased]

- [修复] 工具执行后的异常记录为不确定副作用并暂停任务；取消后补齐全部工具调用结果，内存会话也需人工核查后恢复。
- [修复] Shell 非零退出码与文件工具错误显示失败，旧 API 切换 Skill 保留新增工具并遵守白名单。
- [改进] 托管文件工具默认隐藏环境密钥文件、Git 元数据和私钥，支持显式 --allow-sensitive-files；Skill 的 max_iterations 控制默认循环预算。
- [改进] CLI 展示有界参数摘要并隐藏内容与命令值；合并 Logger 的重复配置逻辑，保留兼容接口。
- [文档] 重写中英文首页，移除失效 MCP 示例、过期 Python 要求与未经验证的对比宣传。
- [测试] 增加 MCP 路由负向测试、四类原生 SDK 多轮协议测试、可选真实工具/流式验收及最小安装、静态检查和审计 CI。

- [修复] MCP 工具路由绑定注册名称，入参不能覆盖审批和 Skill 白名单对应的远端工具。

- [新功能] JSONL 会话恢复、系统写入锁、不确定工具结果人工解决及保留原记录的上下文摘要。

- [修复] CLI 不再重复注入当前用户消息，日志不再输出 API Key 前缀。
- [改进] 默认 CLI 工具限制为 Coding Tools；原有基础工具保持显式可用。
- [文档] 记录六阶段迁移、权限边界和可复现源码统计。
- [新功能] 异步 Harness、实例级工具、静态插件生命周期和统一授权入口。
- [改进] Python 最低版本提升至 3.11，打包元数据统一到 pyproject.toml。
- [新功能] any-llm 异步模型适配、自定义 Provider、完整流式工具组装及 Provider 密钥隔离。
- [新功能] 简化 SKILL.md 读取与可恢复工具白名单，官方 MCP 2.3 stdio 插件。
- [改进] 移除手写 MCP 传输；旧隐式进程 API 明确提示迁移到生命周期插件。
- [改进] 默认 CLI 迁移到 Harness，增加会话、模型、插件和 Skill 命令；旧教学 CLI 通过 --legacy 使用。
- [测试] 增加 Windows/Linux 锁定依赖 CI、MCP 子进程集成、流式签名和 CLI 回归。
